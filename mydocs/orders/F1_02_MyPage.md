# [F-M1-02] 마이페이지 (프로필 조회, 닉네임 수정, 로그아웃)

## 1. 작업 개요
로그인 후 접근할 수 있는 메인 탭바 중 '내 정보(마이페이지)' 화면을 구현한다. 피그마 디자인을 바탕으로 유저의 프로필 정보와 매너온도를 보여주고, 프로필 수정 모달/기능 및 로그아웃을 제공한다.

## 2. 요구사항 및 주요 기능
- **공통 컴포넌트**: 
  - 화면 하단에 고정되는 하단 네비게이션 바(`BottomNav.tsx`) 구현. (홈, 채팅, 내 정보)
- **마이페이지(`MyPage.tsx`)**:
  - `useAuthStore`에서 유저 정보(닉네임, 매너온도)를 읽어와 렌더링.
  - 당근마켓 특유의 매너온도 바(`ProgressBar`) 구현 (온도에 따른 컬러 변화).
  - [프로필 수정] 버튼 클릭 시 모달창을 띄우고, 백엔드(`PATCH /api/v1/users/me`)를 호출해 닉네임을 변경한 뒤 Zustand 스토어를 업데이트한다.
  - [로그아웃] 버튼 클릭 시 `useAuthStore`를 초기화하고 로그인 페이지로 리다이렉트한다.

## 3. UI/UX 디자인 (피그마 반영)
- 상단 헤더: "내 정보" 타이틀 및 우측 설정(톱니바퀴) 아이콘.
- 레이아웃: 회색 배경 모바일 앱 컨테이너, 요소별 카드로 분리된 화이트/연그레이 섹션.
- 매너온도바: 36.5도 기준 당근색, 높아지면 붉은색 등으로 게이지가 채워지는 UI.

## 4. 완료 조건 (DoD)
- [ ] 하단 탭바를 통해 라우팅 이동이 자연스러운지 확인.
- [ ] 마이페이지 UI 퍼블리싱 (피그마 디자인 최대한 동일하게).
- [ ] 닉네임 수정 기능이 실제 백엔드 연동을 통해 정상 동작하는지 테스트.
- [ ] 로그아웃 클릭 시 스토리지 정보가 지워지고 로그인 화면으로 튕기는지 확인.
