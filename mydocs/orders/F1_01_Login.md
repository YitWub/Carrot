# [F-M1-01] Zustand 전역 상태 세팅 및 구글 로그인 연동

## 1. 작업 개요
프론트엔드에서 유저의 로그인 상태(인증 정보)를 전역으로 관리하기 위해 Zustand를 세팅하고, 구글 로그인 버튼을 클릭했을 때 Firebase Auth 토큰을 백엔드 `/api/v1/auth/login`으로 보내어 회원가입/로그인을 처리하는 플로우를 구현한다.

## 2. 요구사항 및 주요 기능
- [ ] `zustand` 및 `axios` 패키지를 설치한다.
- [ ] `store/useAuthStore.ts`를 생성하여 `user`, `isLoggedIn`, `login`, `logout` 전역 상태를 관리한다.
- [ ] 로그인 페이지(`LoginPage.tsx`)에서 구글 로그인 버튼을 구현한다. (당근마켓 스타일의 깔끔한 주황색 UI)
- [ ] Firebase 로그인 성공 시 반환되는 Token을 백엔드에 전송하여 커스텀 User 객체를 응답받고, 이를 Zustand 스토어에 저장한다.

## 3. UI/UX 디자인 (피그마 반영)
- 버튼 테마: 당근마켓 고유의 주황색 (`#FF7E36`).
- 모바일 환경에 적합한 반응형 레이아웃 적용.
- 로딩 중일 때 버튼 비활성화 및 로딩 스피너 표시.

## 4. 완료 조건 (DoD)
- [ ] Zustand 세팅 및 스토어 생성 완료.
- [ ] 백엔드 로그인 API 연동 및 상태 저장 로직 테스트 완료.
- [ ] 로그인 성공 시 로컬스토리지에 인증 정보가 캐싱되어야 함.
