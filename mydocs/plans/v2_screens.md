# 당근마켓 V2 화면 목록 (Screen Inventory)

기존 Carrot 프로젝트 코드를 업그레이드하기 위해, Figma에서 그려야 할(또는 코드로 직접 구현해야 할) 화면들의 목록과 각 화면별 필수 UI 컴포넌트들을 정의합니다.

## 1. 홈 화면 (Home)
앱 접속 시 가장 먼저 보이는 상품 리스트 화면입니다.
- **주요 UI:** 
  - 상단: 동네 이름(예: 역삼1동), 검색 아이콘, 알림 아이콘
  - 중앙: 상품 리스트 (썸네일 이미지, 제목, 동네, 등록 및 끌올 시간, 가격, 찜/채팅/ 아이콘 및 그 개수)
  - 우측 하단: 글쓰기 플로팅 버튼 (Task 2에서 정렬 수정한 주황색 십자가 버튼 재사용)
  - 하단(GNB): 홈, 채팅, 나의 당근 탭바

## 2. 상품 상세 화면 (Product Detail)
리스트에서 특정 상품을 클릭했을 때 들어가는 상세 페이지입니다.
- **주요 UI:**
  - 상단: 뒤로가기, 공유하기 버튼, 다중 이미지 스와이퍼(Carousel)
  - 판매자 정보 구역: 프로필 사진, 닉네임, 매너온도 바(Bar)
  - 본문 구역: 글 제목, ,가격, 시간, 본문 내용, (조회수,찜,채팅 아이콘 및 숫자)
  - 하단 고정바(Sticky): 찜하기(하트) 버튼, '채팅하기' 버튼

## 3. 글쓰기 화면 (Product Write/Edit)
플로팅 버튼을 눌렀을 때 나오는 상품 등록 화면입니다.
- **주요 UI:**
  - 상단: 닫기(<), '중고거래 글쓰기' 타이틀
  - 폼 구역: 
    - 카메라 아이콘 (이미지 업로드 버튼 및 등록된 이미지 썸네일 가로 스크롤, 최대 10장 표기)
    - 제목 입력칸
    - 가격 입력칸
    - 내용 입력칸 (Textarea)
  - 하단 고정바(Sticky): 작성 완료 버튼

## 4. 채팅 화면 (Chat)
당근마켓의 핵심인 1:1 대화 기능입니다.
### 4.1. 채팅 목록 화면: 나와 대화 중인 유저들의 프로필, 마지막 메시지, 시간, 안 읽은 알림 배지
### 4.2. 채팅방 상세 화면:
  - **주요 UI** 
    - **상단(Sticky)** 
      - 최상단: 뒤로가기 버튼, 닉네임, 매너온도, 삼지창 버튼(신고하기, 채팅방 나가기 기능)
      - 중상단: 상품이미지, 제목, 가격
    - **채팅 화면
      - 실시간 말풍선 UI, 읽음/읽지 않음 표시, 상대방 프로필 표시, 대화 내역 날짜 표시
    - **하단 고정바(Sticky)** 
      - 하단 메시지 입력창 및 전송 버튼


## 5. 나의 당근 (My Page / Profile)
'계정 관리'가 이루어지는 곳입니다.
- **주요 UI:**
  - 내 프로필 구역: 프로필 사진 수정, 닉네임 수정, 매너온도 확인기능
  - 메뉴 리스트: 관심목록(찜), 판매내역, 구매내역
  - 설정: 로그아웃 버튼, **회원 탈퇴(빨간색 텍스트로 위험 경고 문구 포함)** 버튼
