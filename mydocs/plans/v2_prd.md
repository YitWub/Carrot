# 용원마켓 v2 (Product Requirements Document)

## 1. 목표
당근마켓의 핵심기능(홈, 채팅, 나의 당근)을 실제 운영이 가능한(Production-Ready) 수준으로 완벽하게 구현한다.

---

## 2. 유저 스토리 (User Stories)
**회원 시스템**
- 사용자는 구글 소셜 로그인 기능을 통해 간편하게 가입 및 로그인할 수 있다.
- 사용자는 닉네임과 프로필 사진을 수정할 수 있다.
- 사용자는 타인의 프로필을 클릭 시 해당 유저의 판매물품 및 매너온도를 확인할 수 있다.
- 사용자는 찜한 상품 목록과 최근 본 글 목록을 확인할 수 있다.
- 사용자는 설정 화면에서 자신의 계정을 안전하게 탈퇴(삭제)할 수 있다.

**상품 관리**
- 사용자는 상품의 사진, 제목, 가격, 내용을 작성하여 등록할 수 있다.
- 사용자는 본인이 올린 상품만 수정 및 삭제할 수 있다.
- 사용자는 본인이 등록한 상품의 상태를 [판매중, 예약중, 거래완료]로 변경할 수 있다.

**상호작용**
- 사용자는 마음에 드는 상품을 '찜'할 수 있다.
- 사용자는 상품 판매자와 1:1 실시간 채팅을 할 수 있다.

---

## 3. 핵심 기능 명세, 제약 조건(Limits) 및 빈 화면(Empty States)

### 3.1. 회원가입 및 탈퇴 (Account Management)
- **회원가입:** Firebase Auth를 사용. 첫 로그인 시 랜덤 닉네임 및 기본 프로필 이미지 배정.
- **프로필 수정 제약(Limit):** 
  - 닉네임은 최소 2자 ~ 최대 10자. 특수문자 금지.
  - 프로필 이미지는 최대 5MB, 형식은 `jpg, png, webp`만 허용.
- **회원탈퇴 정책 (Soft Delete):** 
  - DB의 `User` 테이블 레코드를 `is_deleted = true`로 변경.
  - 탈퇴한 유저의 상품 글은 함께 노출 중단(비활성화) 처리.
  - 기존 채팅방 기록은 남겨두되, 상대방이 프로필 클릭 시 "알 수 없는 사용자입니다" 토스트 알림 노출 후 접근 차단.
- **빈 화면(Empty State):** 
  - '최근 본 글' 탭 진입 시 데이터가 없으면 "최근 본 글이 없습니다" UI 노출. (데이터는 브라우저 LocalStorage에 최대 20개 저장)

### 3.2. 상품 게시판 (Product Board)
- **글쓰기 제약(Limit):** 
  - 다중 이미지는 최소 1장 ~ 최대 10장 필수 첨부. (1장당 5MB 제한)
  - 가격은 0원(무료나눔) ~ 99,999,999원 사이 숫자만 입력 가능.
- **이미지 최적화:** 프론트엔드에서 업로드 전 가로 폭 1200px 이하의 WebP 형식으로 압축 수행.
- **상품 상태 변경:** 작성자 본인만 상세 페이지에서 상태 변경 드롭다운 접근 가능.
- **빈 화면(Empty State):** 
  - 홈 화면 진입 시 해당 동네에 상품이 없으면 "우리 동네 첫 상품을 등록해보세요!" UI 노출.

### 3.3. 채팅 시스템 (Chat)
- **채팅 제약(Limit):** 메시지는 한 번에 최대 1000자까지만 전송 가능. 빈 메시지 전송 불가.
- **빈 화면(Empty State):** 채팅 목록 탭에 진입했을 때 대화방이 없으면 "진행 중인 채팅이 없습니다" UI 노출.

### 3.4. 시스템 공통 (Common)
- **로딩 상태 방어:** API 호출(글쓰기 등록 등) 중일 때는 버튼 내부에 스피너(Spinner)를 띄우고 버튼을 비활성화(Disabled) 처리하여 '따닥(중복 클릭)' 방지.
- **글로벌 에러 핸들링:** 백엔드 500 에러 발생 시 "서버에 알 수 없는 오류가 발생했습니다" 빨간색 토스트 알림 띄우기.

## 4. 인수 조건 (Acceptance Criteria - AC)
*개발 완료 시 아래 테스트를 통과해야 합니다.*

- [ ] (회원) 프로필 사진 6MB 업로드 시도 시 "5MB 이하만 가능합니다" 경고가 뜨는가?
- [ ] (회원) 회원 탈퇴 시 "정말 탈퇴하시겠습니까?" 컨펌 창이 뜨며, 탈퇴 후 자동 로그아웃 되는가?
- [ ] (회원) 탈퇴한 회원의 상품이 홈 화면 리스트에서 사라졌는가?
- [ ] (상품) 내 글이 아닌 남의 글에 들어갔을 때 '수정/삭제' 및 '상태 변경' 버튼이 안 보이는가?
- [ ] (상품) '최근 본 글' 클릭 후 다른 기기에서 접속했을 때 로컬스토리지 특성상 동기화되지 않음을 인지하고 있는가?
- [ ] (상품) 상품 작성 완료 버튼을 연속으로 3번 클릭해도 DB에 데이터가 1번만 저장되는가?
