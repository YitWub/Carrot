# Task 2 — UI 버그 수정 및 디자인 개선

이슈: #Task-2
브랜치: local/main (이전 devel)
작성일: 2026-07-01

## 1. 목적
당근마켓 클론 프로젝트의 화면 완성도를 높이기 위해, UI 버그를 수정하고 브랜드 정체성에 맞는 스타일을 적용한다.

이번 Task 범위:
- 홈 화면 우측 하단의 글쓰기 플로팅 버튼(십자가) 정중앙 정렬
- 프로필 화면의 구글 로그인 버튼 색상을 당근마켓 주황색으로 변경
- 구글 로고 아이콘 디자인 개선 및 버튼 내 여백 조정

## 2. 현재 판단
- 플로팅 버튼의 경우 `Home.css`에서 `display: flex`가 누락되어 브라우저 기본 렌더링에 의해 아이콘이 치우쳐 보임. CSS 속성 강제가 필요함.
- 로그인 버튼은 기본 파란색 구글 UI를 쓰고 있어 앱 테마와 어울리지 않음. 버튼의 `backgroundColor`를 당근 주황색(`#ff7e36`)으로 하드코딩 교체.
- 로고 렌더링 시 기존 사각형 흰 배경 대신 원형(`borderRadius: 50%`)을 적용하면 디자인 일체감이 올라감.

## 3. 구현 중 포인트
신규 파일: 없음
수정 파일:
- `frontend/src/pages/Home.css` (플로팅 버튼 정렬 추가)
- `frontend/src/pages/Profile.tsx` (로그인 버튼 컴포넌트 인라인 스타일 대거 수정)

## 4. 검증 대기
실행 검증:
- `cd frontend && npm run dev`
- 웹 브라우저 로컬 접속 (`http://localhost:5999`)

검증 결과:
- `Home.css` 변경 후 십자가 아이콘 수직/수평 정중앙 정렬 통과
- `Profile.tsx` 변경 후 주황색 버튼 렌더링 통과
- 로그인 텍스트와 버튼 사이 간격(`gap: 16px`) 확장 시각적 확인 통과
- 원형 흰색 배경 내부에 구글 G 로고 정상 삽입 확인 통과

## 5. 현재 결과
이번 Task 2에서 반영된 핵심:
- `.floating-button` 정렬 버그 완벽 수정
- 구글 로그인 버튼 브랜드 테마(Orange) 덧씌우기 완료
- UI 간격 조절로 인한 시각적 안정감 개선
- 변경된 코드를 `main` 브랜치로 병합하고 운영 서버(Nginx)에 성공적으로 배포 완료
